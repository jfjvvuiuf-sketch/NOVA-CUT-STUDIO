✦ NOVA CUT ULTRA Guide

1. Add multiple videos using Add Multiple Videos.

2. Click a video in Media, then add it to the timeline.

3. Drag timeline clips left/right. Use the handles to change their duration.

4. Import multiple sounds and add them to AUDIO.

5. Add Text, FX and Transitions directly to the timeline.

6. Select any clip to edit its properties on the right.

7. Press Export to render the canvas to WebM.
